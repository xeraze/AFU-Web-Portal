# Armed Forces of Ukraine — Web Portal

### Roblox RP information and coordination interface

A community-made web portal for an Armed Forces of Ukraine faction within a Roblox RP environment.

</div>

## Overview

**AFU Web Portal** is a lightweight static frontend focused on presenting faction information, organizational material, and application-oriented content through a military-themed interface.

The project is intentionally built without a heavy frontend framework, keeping the page fast and easy to deploy.

## Highlights

- Military / institutional visual language
- Responsive frontend layout
- Interactive application form logic
- Structured presentation of ranks, orders, and informational content
- Lightweight client-side architecture

## Tech Stack

| Technology | Role |
|---|---|
| HTML5 | Page structure |
| CSS3 | Layout and visual design |
| JavaScript | Interactive behaviour and forms |
